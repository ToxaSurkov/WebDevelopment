# Занятие 1 — актуальные приложения для демонстрации

**Это единый комплект учебных примеров, порядок папок совпадает с порядком лекции.**

## Демонстрации в нужном порядке

| № | Папка | Что объясняем | Как запустить |
|---|---|---|---|
| 1 | `apps/01_information_site` | Многостраничный сайт: HTML, CSS и ссылки | Дважды нажать `index.html`, затем выбрать «Посмотреть без CSS» |
| 2 | `apps/02_browser_text` | JavaScript исполняется в браузере | Дважды нажать `index.html`, затем выбрать «Посмотреть без CSS» |
| 3 | `apps/03_python_catalog` | Браузерный frontend, отдельный Python backend, HTTP, JSON | В папке выполнить `python server.py`, затем открыть `http://127.0.0.1:8765/` |
| 4 | `apps/04_gradio_text` | Python-функция и автоматически созданный веб-интерфейс | Установить зависимости из `requirements.txt`, запустить `python app.py` |
| 5 | `apps/05_streamlit_text` | Python-скрипт, виджеты, rerun | Установить зависимости, запустить `python -m streamlit run app.py` |
| 6 | `apps/06_streamlit_dashboard` | Графики и фильтрация таблиц | Установить зависимости, запустить `python -m streamlit run app.py` |
| 7 *(дополнительно)* | `apps/07_browser_clustering` | **K-means и DBSCAN, серьёзные вычисления в одном браузере, Canvas, без сервера** | Дважды нажать `index.html`; ничего устанавливать не нужно |

Для Windows можно использовать `start_windows.cmd`, для macOS/Linux — `start_mac_linux.sh` в соответствующей папке. Перед первым запуском Gradio и Streamlit потребуется установить зависимости из `requirements.txt` (обычно `python -m pip install -r requirements.txt`).

## Дополнительный пример: кластеризация только в браузере

Откройте `apps/07_browser_clustering/index.html`. В нём реализованы два настоящих алгоритма кластеризации **на JavaScript**, визуализация точек с помощью HTML Canvas, генерация наборов, пошаговое выполнение и сравнение алгоритмов. Запускать `server.py` для этого приложения **не нужно**. Наиболее эффектный показ: **«Два кольца» → «Сравнить K-means и DBSCAN»**. Дополнительная инструкция и построчные комментарии — внутри папки примера.
