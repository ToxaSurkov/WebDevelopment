# Jupyter Notebook 7: кто за что отвечает

Frontend = браузер (HTML/CSS/JS/TS), backend = Jupyter Server на Python, Kernel = отдельный процесс исполнения кода.

| Функция | Frontend | Jupyter Server | Kernel |
|---|---|---|---|
| Ввод и редактирование кода | Редактор ячеек, курсор, перемещение | При сохранении записывает изменения | Не нужен для редактирования |
| Выполнение Python | Нажатие Run, отправка кода, показ результата | Соединяет frontend с ядром, управляет сессией | Выполняет код и хранит переменные |
| Таблицы и графики | Отрисовывает результаты, HTML, SVG, PNG | Передаёт сообщения с результатом | Вычисляет данные, формирует вывод |
| Сохранение и автосохранение | Формирует и отправляет содержимое документа | Через Contents API записывает .ipynb | Обычно не участвует |
| Открытие и просмотр файлов | Показывает каталог, выбор документов | Получает список и содержимое с диска | Обычно не участвует |
| Автодополнение и справка | Запрашивает подсказки, показывает список | Передаёт сообщения к активному ядру | Возвращает информацию об именах и объектах |
| Restart / Interrupt | Кнопки и отображение статуса | Управляет процессом ядра | Перезапускается или прерывает исполнение |
| Markdown и формулы | Редактирует и отображает разметку | Сохраняет документ | Не нужен для отображения Markdown |
| Выбор языка / ядра | Показывает доступные ядра | Получает kernelspec, создаёт сессию | Новое ядро исполняет свой язык |
| Интерактивные виджеты | JS-компоненты и события | Передаёт сообщения / comm | Python-обработчики и расчёты |
| Экспорт и скачивание | Запускает экспорт и скачивание | Часто обрабатывает файл и конвертацию | Не обязательно, кроме экспорта с выполнением |
| Доступ и авторизация | Передаёт токен/куки с запросами | Проверяет разрешения и ограничения | Доступ к ядру требует серверной защиты |

## Демонстрация

1. `jupyter notebook` → `http://localhost:8888` (порт может измениться).
2. Выполнение ячейки; `Network` → XHR и WS.
3. Сохранение `.ipynb` — документ JSON, а не память процесса.
4. Restart Kernel → переменная пропадает.

*Сервер обслуживает API и управляет ядрами; исполнение пользовательского кода происходит в Kernel.*
