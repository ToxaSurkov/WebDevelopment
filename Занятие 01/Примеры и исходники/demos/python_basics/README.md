# Минимальный код Python для слайда 18

`count_words.py` — настоящий запускаемый файл; он не является веб-сервером.

Запуск: `python count_words.py` (или `python3 count_words.py`).

Результат: `2` в терминале. Объяснение: `def` объявляет функцию; `text` принимает строку; `text.split()` разделяет её по пробелам, `len(...)` считает полученные части, `return` возвращает число, `print` выводит число в терминал.

В отличие от `apps/03_python_catalog/server.py`, эта программа **ничего не слушает по HTTP** — это пример самого языка Python, прежде чем переходить к серверным программам.
