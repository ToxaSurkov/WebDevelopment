# Первая лекция: что происходит «под капотом» Gradio и Streamlit

Это **дополнительные короткие демонстрации** к новой презентации (33 слайда). Ничего не нужно изменять в основном наборе учебных приложений.

## Установка (один раз)

Требуется Python 3.10+ и доступ в интернет для установки пакетов.

```bash
python -m pip install -r requirements.txt
```

## Gradio

```bash
python demo_gradio_callbacks.py
```

1. В браузере введите текст и нажмите Submit.
2. Посмотрите в терминал: строка `[Python] Gradio вызвал count_chars...` появится **при вызове функции**.
3. Объяснение: браузер передал данные локальному Gradio-серверу; тот выполнил `count_chars` внутри Python-процесса и вернул результат.
4. Закройте процесс Python и попробуйте повторить действие: функция не сможет обработать запрос.

## Streamlit

```bash
python -m streamlit run demo_streamlit_reruns.py
```

1. Откройте локальную страницу по адресу из терминала.
2. Изменяйте текст; по умолчанию **скрипт выполняется снова сверху вниз**, что можно увидеть по строкам `[Python] Streamlit запустил скрипт...` в терминале.
3. Нажмите «Добавить к счётчику» 2–3 раза. Значение не исчезает, поскольку сохранено в `st.session_state`.
4. Объяснение: это модель «сценарий отображения как Python-скрипт», отличающаяся от связывания события с отдельным Python-обработчиком в Gradio.

## Важно для преподавателя

- Обе технологии создают **браузерный frontend** и запускают **локальный Python-процесс** для основной обработки.
- Это не означает, что браузер выполняет обычный Python-код напрямую.
- В современном Gradio есть отдельные клиентские функции и механизм очередей; модель на слайде намеренно упрощена.
- В Streamlit full-script rerun — **поведение по умолчанию**; forms, callbacks и fragments могут менять его.
- Обе библиотеки поддерживают сложные настройки, но для полностью свободного сложного интерфейса могут потребоваться дополнительные средства frontend-разработки.
- Демонстрации требуют пакетов; при невозможности установки используйте приведённый код и подготовленный скриншот терминала.
