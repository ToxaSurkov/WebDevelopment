# Сравнение HTML с CSS и без CSS

## Как демонстрировать в первой лекции

1. Откройте `index.html` двойным щелчком — сайт с оформлением.
2. Нажмите **«Посмотреть эту страницу без CSS»**. Откроется копия той же страницы, но без подключения `styles.css`.
3. Нажмите **«Вернуть оформление CSS»** и сравните результат.
4. Покажите исходный код обеих страниц и найдите в `<head>` строчку `<link rel="stylesheet" href="styles.css">` — в варианте без CSS она закомментирована.
5. Перейдите на «Счёты» в режиме без CSS: ссылки работают, потому что это HTML, а не JavaScript.

### Что именно меняется?

- **Сохраняется:** текст, заголовки, ссылки, изображения, семантика HTML, переходы между страницами.
- **Изменяется:** шрифты, цвета, отступы, сетка из карточек, фон и другие свойства оформления.
- **Важное уточнение:** браузер даже без нашего `styles.css` применяет свои стандартные стили (user-agent stylesheet). Поэтому сайт не превращается в «полностью неоформленный набор символов».
- **JavaScript:** ни в одном из вариантов не используется. Переключение сделано двумя наборами статических страниц с обычными ссылками.

### Файлы

- `index.html`, `abacus.html` и другие страницы в корне — **с CSS**.
- `without-css/` — те же четыре страницы **без CSS**.
- `styles.css` — общие правила оформления.
- `images/` — иллюстрации для обеих версий.

Обе версии работают без Python, сервера, npm и интернет-подключения.
