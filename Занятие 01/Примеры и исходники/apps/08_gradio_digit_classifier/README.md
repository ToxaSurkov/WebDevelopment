# Gradio — классификатор рукописных цифр

Это более содержательный пример специализации Gradio: **предобученная модель + интерфейс для обращения к Python-функции**. Сама модель обучена на `sklearn.datasets.load_digits`; веса сохранены в `digits_model.joblib`, поэтому при каждом нажатии она **не переобучается**. Изначально в браузере нет Python-модели: Gradio отправляет изображение в локальный Python-процесс и возвращает результат.

Запуск:

```bash
python -m pip install -r requirements.txt
python app.py
```

Открыть http://127.0.0.1:7862/ . Выбрать один из образцов цифр и нажать «Распознать». Обучить заново при необходимости: `python train_model.py`.

Ключевые строки: `model = joblib.load(...)` загружает модель; `predict_digit(image, invert)` подготавливает изображение и считает вероятности; `predict_button.click(...)` связывает кнопку и Python-функцию с тремя выходными компонентами.

Встроенные образцы взяты из набора `load_digits` и преобразованы в PNG. Модель ожидает **светлую цифру на тёмном фоне**; для пользовательских картинок включите инверсию, если фон светлый. Этот учебный классификатор не рассчитан на любые рукописные фотографии: он обучен на маленьких изображениях 8×8.
