# 07 · Кластеризация в браузере (без сервера)

Откройте `index.html` двойным щелчком. **Python, интернет, npm, сервер и установка библиотек не нужны.** Работает из локальных файлов (`file://`).

## Что показывает приложение

- Генерация двухмерных данных: облака, дуги, кольца и случайные точки.
- **K-means:** задание K, пошаговое распределение точек по ближайшим центрам и изменение положения центров.
- **DBSCAN:** плотностные кластеры, радиус `ε`, параметр `minPts`, выделение шума.
- Визуализация на HTML Canvas; пошаговый режим и автоматическое выполнение.
- Сравнение результатов **двух алгоритмов на одном наборе точек**; на кольцах особенно заметно, что подходы разделяют данные по-разному.
- Добавление точек щелчком по графику и локальный импорт CSV (`x,y`, значения в пределах 0–100).

## Какие файлы показать студентам

| Файл | Назначение |
|---|---|
| `index.html` | **HTML** — описывает форму, кнопки, текст и элемент `<canvas>`; подключает CSS и JS |
| `styles.css` | **CSS** — задаёт оформление и расположение элементов, но не считает кластеры |
| `algorithms.js` | **JavaScript** — математические алгоритмы K-means и DBSCAN, генерация данных |
| `app.js` | **JavaScript** — события кнопок, взаимодействие с DOM и рисование через Canvas API |
| `sample_points.csv` | Образец локальных данных для импорта |

В файлах есть подробные комментарии на русском языке, они не отображаются на веб-странице, но видны в редакторе.

## Демонстрация на 5–8 минут

1. **Откройте `index.html`.** Скажите, что адрес начинается с `file://` и никакой Python-процесс не запущен.
2. Выберите **«Три облака» → K-means → «Один шаг»**. Покажите центры кластеров и изменение их положения при следующих шагах.
3. Выберите **«Два кольца» → K-means → «Сравнить K-means и DBSCAN»**. K-means обычно делит кольца на сектора, DBSCAN выделяет концентрические кольца.
4. Покажите `index.html`: строчку `<canvas ...>` и подключение `algorithms.js` и `app.js`.
5. Покажите в `algorithms.js` класс `KMeans` и метод `step()`, а в `app.js` — `addEventListener('click', ...)` и `canvas.getContext('2d')`.
6. Включите в DevTools вкладку **Network**, выключите интернет, выполните несколько шагов. Новых HTTP-запросов не будет, поскольку вычисления не требуют сети.
7. Дополнительно импортируйте `sample_points.csv`, если хотите показать чтение локальных файлов через File API.

## Пояснения и ограничения

- Здесь представлены компактные учебные реализации двух алгоритмов, а не промышленная библиотека ML.
- K-means применяет вариант k-means++ для начального выбора центров.
- DBSCAN перебирает соседей простым полным поиском (для нескольких сотен точек этого достаточно).
- Параметры DBSCAN чувствительны к масштабу и плотности данных, поэтому для разных наборов полезно выбирать разные `ε`.
- Импорт CSV сознательно ограничен двумя числовыми столбцами и значениями от 0 до 100; CSV-файл читается локально.
- Алгоритмы вычисляются в основном JavaScript-потоке браузера. Большие датасеты лучше обрабатывать с помощью Web Workers или более специализированных реализаций.
