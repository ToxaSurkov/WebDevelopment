# Streamlit — аналитическая панель продаж

Более содержательный пример специализации Streamlit: **загрузка таблицы, фильтры, показатели, динамические графики и CSV-выгрузка**. Отдельные HTML и JavaScript писать не требуется.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Попробуйте изменить регион, канал, товар и период. Streamlit **по умолчанию заново выполняет скрипт**, пересчитывает таблицу `filtered` и обновляет метрики и графики. В `load_data()` используется `@st.cache_data`, чтобы при этом не считывать один и тот же файл снова. Если изменить фильтры так, что не останется строк, отобразится предупреждение.

Учебный файл `sales.csv` — **синтетические данные**, созданные для демонстрации: они не являются настоящей коммерческой статистикой. Для преподавателя главные строки: `st.sidebar.multiselect`, `filtered = ...`, `st.metric`, `st.line_chart`, `st.bar_chart` и `st.download_button`.
