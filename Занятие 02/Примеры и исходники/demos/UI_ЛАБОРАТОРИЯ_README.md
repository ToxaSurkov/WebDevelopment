# UI-лаборатория: одинаковый визуальный уровень, разная пригодность

Откройте `ui_design_lab.html` напрямую в браузере. Сравните **Вариант А** и **Вариант Б** для конкретной задачи: найти работу на тему визуализации за 2025 год. Оба интерфейса выполнены в едином профессиональном стиле; вариант А не испорчен декоративно.

- А больше соответствует «просматривать редакционные подборки»: сначала большие рекомендации, поиск ниже, фильтр года скрыт под «Дополнительные параметры», пустой результат не даёт рядом исправляющего действия.
- Б лучше соответствует «быстро найти запись»: сразу видны поиск и год, количество результатов, пустое состояние с доступным сбросом.

Проверьте запрос `визуализация`, год `2025`, затем `несуществующее`. Переключите ширину. Объясните конкретные пользовательские издержки, а не вкусовое «А хуже выглядит».

HTML-лаборатория — автономное приложение на обычном JavaScript, **не React**. React-каталог находится отдельно в `apps/02_react_publications`.
