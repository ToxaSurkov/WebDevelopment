# 02 — Каталог публикаций на React

**Все 60 публикаций вымышлены.** Данные созданы для демонстрации компонентного интерфейса, фильтров и производных значений. Никакого собственного backend или API здесь нет.

## Запуск

Установите Node.js 20.19+ или 22.12+. При первом `npm install` требуется доступ к реестру npm.

```bash
npm install
npm run dev
```

Откройте адрес из терминала. Для проверки чистой логики **без React**: `npm test`. Для сборки: `npm run build`.

## Файлы для лекции

- `index.html` — контейнер React; почти нет интерфейсного HTML.
- `src/main.jsx` — создание React root.
- `src/App.jsx` — общие state, выбор экрана, derived list, props.
- `src/components/SearchFilters.jsx` — управляемые формы через props и callbacks.
- `src/components/PublicationCard.jsx` — много карточек из одного компонента и локальный state развёрнутого описания.
- `src/components/Statistics.jsx` — производная статистика по той же коллекции.
- `src/lib/catalog.js` — функции фильтрации и агрегации вне React.
- `src/data/publications.json` — фиктивные данные.
