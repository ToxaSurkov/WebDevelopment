# 01 — Текстоскоп на React

Демонстрация, как знакомый браузерный анализатор из занятия 1 выглядит на React. Вся обработка выполняется локально в браузере.

## Запуск

Нужен Node.js 20.19+ или 22.12+ и интернет **на этапе первой установки зависимостей**.

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно http://127.0.0.1:5173/). Для готовой сборки: `npm run build`.

`npm test` проверяет чистую логику анализатора без установки React.

## Как показывать

1. `index.html`: контейнер `root`, а не вся разметка.
2. `src/main.jsx`: React подключается к DOM.
3. `src/App.jsx`: состояние, JSX, обработчики, props.
4. `src/components/Metric.jsx`: многократное использование компонента.
5. `src/lib/analyze.js`: чистая вычислительная логика (без DOM и React).

При открытии DevTools → Elements студенты увидят настоящие HTML-элементы, созданные React.
