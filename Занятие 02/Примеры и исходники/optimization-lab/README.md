# Лаборатория оптимизации

Из папки «Примеры и исходники» запустите `npm run dev:lab`. Откройте [React](http://127.0.0.1:5176/) или [Svelte](http://127.0.0.1:5176/svelte.html). Обе страницы обслуживает один Vite.

- **Реактивность и state.** Меняйте фильтры в примерах с локальным состоянием и производными данными. В React откройте «Вычисления», чтобы сравнить число запусков расчёта с `useMemo` и без него.
- **Списки.** Отметьте строку и измените порядок, затем сравните число DOM-элементов полной и виртуализированной выдачи.
- **Загрузка кода.** На вкладке Network выберите JS и впервые откройте «Lazy: статистика» (React) или «Ленивая статистика» (Svelte). В сборке для обоих отчётов создаются отдельные JS-чанки.

## Как запустить сетевое демо

В отдельном окне Anaconda Prompt перейдите из папки «Примеры и исходники» в `optimization-lab\backend` и выполните

    python -m pip install -r requirements.txt
    python -m uvicorn main:app --host 127.0.0.1 --port 8000

Откройте «Сеть» и сравните режимы в DevTools → Network → Fetch/XHR. Для обоих вариантов используется один API, Vite проксирует запросы `/api` на порт 8000.
