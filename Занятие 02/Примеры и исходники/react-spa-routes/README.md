# React SPA

Один HTML-документ и маршруты /, /stats и /about. При переходах фильтры сохраняются в App.

После установки зависимостей в родительской папке запустите оттуда `npm run dev:spa`.

[Общие данные, стили и инструкции](../README.md).

При публикации с BrowserRouter настройте отдачу index.html для прямых запросов к /stats и /about.
