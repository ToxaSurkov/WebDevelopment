# SPA с тремя экранами на React

## Запуск
```bash
npm install
npm run dev
```
Откройте адрес Vite, обычно http://127.0.0.1:5173/.

## Как проверить SPA
1. Откройте DevTools → Network, включите Preserve log и тип **Doc**.
2. Перезагрузите `/`: появится запрос одного HTML-документа.
3. Переключайтесь между **Каталогом**, **Статистикой**, **О проекте**. URL изменяется (`/`, `/stats`, `/about`), но новые документы не загружаются.
4. Введите в каталоге «виз». Перейдите в Статистику и вернитесь — в каталоге запрос остался: `query` хранится в `App`.
5. Нажмите F5 на `/stats` — страница откроется благодаря History API fallback dev-сервера Vite. На статическом хостинге для прямых ссылок `/stats` и `/about` нужно настроить fallback на `index.html` (или использовать hash-based роутер).

## Что в коде
- `index.html` — единственный HTML entrypoint.
- `src/main.jsx` — BrowserRouter.
- `src/App.jsx` — NavLink, Routes, Route и общий state `query`, `year`.
- `src/pages/` — три экранных React-компонента.
- `src/publications.json` — тот же набор 9 публикаций, что и в базовом каталоге.
- `react-router` — дополнительный пакет npm для клиентской маршрутизации.

## Важно
SPA — не обязательно один экран. Смена экранов выполняется в браузере без новой загрузки документа, но API-запросы при этом возможны в других приложениях.
