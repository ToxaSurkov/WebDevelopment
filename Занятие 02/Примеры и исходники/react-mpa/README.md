# MPA с тремя HTML-страницами, каждая написана на React

## Запуск
```bash
npm install
npm run dev
```
Откройте адрес Vite, обычно http://127.0.0.1:5173/.

## Как проверить MPA
1. DevTools → Network → Preserve log → тип **Doc**.
2. Из каталога перейдите по меню на **Статистику** и затем **О проекте**.
3. Для каждого перехода браузер запрашивает новый HTML-документ: `/stats.html`, `/about.html`.
4. Введите в каталоге «виз», перейдите в Статистику и вернитесь: фильтр сбросится, так как старый React root был уничтожен при полной навигации.
5. `npm run build` создаёт в `dist/` три HTML-файла (плюс CSS и JS). Их можно разместить на обычном статическом хостинге без SPA fallback.

## Где смотреть код
- `index.html`, `stats.html`, `about.html` — три HTML-документа.
- `src/catalog.jsx`, `src/stats.jsx`, `src/about.jsx` — три независимых точки запуска React (`createRoot`).
- `src/SiteLayout.jsx` — обычные ссылки `<a href=...>` для полной навигации.
- `src/pages/` — те же экранные компоненты, что и в SPA.
- `vite.config.js` — несколько входных HTML для сборки Vite.

## Важно
MPA может быть на React. Деление SPA/MPA связано с загрузкой документов и моделью навигации, а не с выбором React против обычного JavaScript.
