# Каталог исследований на обычном JavaScript

Версия того же каталога, что в `react-catalog/` и `svelte-catalog/`, но без React, Svelte и сборщика. Те же девять записей, поиск по теме и названию, фильтр по году, счётчик, пустая выдача и сброс. Стили почти идентичны для честного сравнения поведения.

**Запуск:** откройте `index.html` в браузере двойным щелчком — интернет и `npm` не требуются. В DevTools → Elements видно, как JavaScript заменяет карточки в DOM; во вкладке Network нет API-запросов при изменении фильтров.

**Где искать нужный код:**

- `src/app.js` — `renderCatalog()` выполняет фильтрацию и меняет DOM вручную; `yearSelect.addEventListener('change', renderCatalog)` запускает это при смене года.
- `src/app.js` — `createCard()` создаёт HTML-элементы каждой карточки.
- `src/publications.js` — те же девять записей, что в React- и Svelte-версиях, но без загрузки JSON через `fetch()`.
- `src/styles.css` — сетка карточек и адаптивная вёрстка.
- `index.html` — начальная HTML-структура: поле поиска, выбор года, пустые контейнеры результатов.

**Демонстрация:** начальное состояние — 9 публикаций; поиск `виз` — 3; год `2025` без поиска — 3; слово `несуществующее` — пустая выдача; «Показать все публикации» возвращает 9.

Сравнение со слайдом 5: без фреймворка функция `renderCatalog()` сама заменяет дочерние узлы `cards`, текст `count` и видимость `empty`; в React аналогичное описание задаётся через JSX и state, а изменения DOM выполняет React.
